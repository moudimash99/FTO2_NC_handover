What the tab is for

The Definitions tab is the dictionary of the dashboard. Every chart that shows a category or a cause uses the words defined here. It is the place to settle "what exactly does this cause cover?", with figures and real examples.

The content

How a defect gets its cause

ShowsThe chain from the official code to the Pareto: 123 official sub-codes → 42 sub-categories → 25 causes → 9 categories.
How to read itEach sub-category gives exactly one cause, each cause belongs to exactly one category. An official code written in the NC decides; otherwise the text of the NC decides, and a defect described with its cause and its consequence is classified on the cause.
How it helpsExplains why a defect lands in a given cause.
