What the tab is for

The Cables tab shows the requests for new cables recorded by the cable team: a cable too short, damaged, missing, cut or not conforming. These requests do not come from SAP but from the cable team's tracker, updated with the dashboard. The tab follows the Aircraft and Period filters only. A switch at the top, Requests / Cables, chooses what every card counts: the requests, or the cables they ask for (the cables written in the request; one when none is written). The key figures give the number of requests, the share due to printing, the lines with a cause, the cables asked for again, and the lines with an action.

The charts

Requests per month and imputation

ShowsThe requests of each month, split by who they are imputed to: the line, the printing (machine or operator), the definition.
How to read itThe share due to printing is given per quarter above the chart.
How it helpsShows whether requests grow, and whether the balance between causes shifts.
A clickKeeps those requests in the list.

Reason × imputation

ShowsA table: each reason (short, damaged, missing, cut, not conforming) against each imputation.
How to read itThe darker the cell, the more requests.
How it helpsShows, for example, where the short cables come from: the line, the printing machine or the definition.
A clickKeeps those requests in the list.

Cable types

ShowsThe cable types asked for most, split by imputation.
How to read itOne bar per type.
How it helpsPoints to the types worth a closer look.
A clickKeeps that type in the list.

Causes (proposed)

ShowsThe cause proposed for each request, read in the cable team's analysis comment.
How to read itUnknown – to analyse counts the requests with no cause yet.
How it helpsA high "to analyse" count means the analysis is behind.
A clickKeeps that cause in the list.

Recurring cables

ShowsThe cables asked for again on several aircraft.
How to read itOne row per cable, with its number of aircraft.
How it helpsA repeated request usually points to a lasting cause rather than a one-off mistake.
A clickKeeps that cable in the list.

Requests

ShowsThe list of the requests, with a search box.
How to read itA label at its top shows the choices made by clicking above; ✕ removes them.
How it helpsReads each request as the cable team wrote it.
