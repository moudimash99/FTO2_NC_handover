What the tool is for

The NC writer, called Saisie structurée de NC on screen, helps you write an NC to the plant's standard: one line per defect, each with its official code from the plant's code sheet, its FIN and its quantity. The tool writes the text for you, the same way every time, so that the dashboard reads every defect right: how many there are, where, and from which cause.

The tool is in French only; this guide gives its words as they appear on screen. On the left are the steps. On the right is the Texte SAP, the text of the NC as it builds up, with the number of defects, the total quantity and the number of major defects; Copier copies it.

From the start to the saved NC

  1. Nouvelle NC (new NC). Type the MSN of the aircraft, choose the Produit, and click where the defect was seen (Détection: Poste, Test, Contrôle Final, Réception, Client, Autre). Then Continuer.
  2. Contexte de découverte (optional): click the start of a sentence, such as Lors du contrôle final, and complete it if needed. A second click removes it.
  3. Ajouter un défaut (add a defect), for each defect, in three steps:
    • Nature: type a word or a code in the search box (contact, obturateur, T04…; accents do not matter), or click a family. Inspection families (Q01 to Q16) and test families (T01 to T08) form two groups; the test ones come first when the detection is Test.
    • Objet: click the element. Each one shows its sub-code and its usual severity; CDVE possible means it has a flight-controls variant.
    • Détails: the Localisation (FIN / zone), chosen among the FINs suggested for this code or typed in the box under them; a Précision and a Complément libre if useful (both optional); the Quantité; the Sévérité, set by the code, which you can change. For a flight-controls circuit, the CDVE switch changes the code to its CDVE variant and the severity to major. Ligne générée shows the line as it will be written. Then Enregistrer le défaut (save the defect).
  4. Action demandée (optional): click a sentence, such as Merci de remettre en conformité, and add your own words.
  5. Vérifier et soumettre (check and submit): the Vérification screen shows a table of the defects and, on the right, the text exactly as it will be sent. Retour aux défauts takes you back to correct it.
  6. Soumettre la NC. The page says NC envoyée: the NC is saved by itself. If the page asks for it, press Submit in the record form below. Nouvelle NC starts the next one.

In the list of defects, Dupliquer le dernier starts a new defect from the last one, with the same code and FIN: handy for a series of the same defect. Each defect can be changed or deleted with its two buttons; the lines are numbered again. Modifier, at the top, changes the MSN, the product or the detection.

The text it writes

### DEFAUTS v1 | PRODUIT: CA Superior | DETECTION: CONTRÔLE FINAL

Lors du contrôle final

DEF 1 - Q01-001 : 100VG301 — Contact — broche 12
DEF 2 - Q03-006 - QTE 3 : 3CBB — Collier

Merci de remettre en conformité

### TOTAL: 4

The first line gives the format, the product and where the defect was seen. Then comes one line per defect: its number, its official code, its quantity when there are several, the FIN, the element and your own words. The last line gives the total quantity: a check that no defect was lost on the way.

The text is made for SAP: paste it into the NC as it is, and leave its DEF lines unchanged. The dashboard reads them one by one, even after SAP has added its stars and spaces.

The checks it makes

  • Continuer stays grey until the MSN, the product and the detection are filled in.
  • No FIN is chosen for you: you pick it or type it.
  • A defect cannot be saved with a quantity that is not a whole number of 1 or more, or with Autre as its location and nothing typed: a red message says what to fix.
  • Vérifier et soumettre stays grey until the NC has at least one defect.
  • If the sending fails, the page says so and the NC is not lost: copy the text with Copier, or try again.

The products offered

MIP A350, MIP 400M, 740VU, PTVU, 300VU, OHP, E Rudder, MFRL, MDCD, and the REC products CA, CA Superior and Element OTP. For another product, choose Autre and type it under the list.

When something is not in the list

  • A product or a detection: choose Autre and type it.
  • A FIN: type it in the box under the list, or choose Autre and type it. A zone will do when there is no FIN.
  • A code: the list is the plant's official code sheet. Try another word, or the code itself, or open the families one by one. If no code really fits, do not take one that is only close: the code decides the cause on the dashboard (below). Tell the person in charge of the dashboard which defect had no code, so that the list can be checked against the official code sheet.

Why the code decides the cause on the dashboard

On the dashboard, each defect is put in one cause, inside one category. For an NC written with this tool, the official code of each defect decides its cause, over any automatic classification. Without a code, the cause is worked out from the words of the text, which can be less precise. So the dashboard puts each of your defects straight in its code's cause, in every chart, in the bell and in the MFT actions. Choose the code with care: it is the cause that will be counted.
