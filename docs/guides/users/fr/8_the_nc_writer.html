À quoi sert l’outil

La Saisie structurée de NC vous aide à écrire une NC au standard de l’usine : une ligne par défaut, chacune avec son code officiel tiré de la fiche de codes de l’usine, son FIN et sa quantité. L’outil écrit le texte pour vous, toujours de la même façon, pour que le tableau de bord lise chaque défaut correctement : combien il y en a, où, et pour quelle cause.

À gauche, les étapes. À droite, le Texte SAP : le texte de la NC tel qu’il se construit, avec le nombre de défauts, la quantité totale et le nombre de défauts majeurs ; Copier le copie.

Du début à la NC enregistrée

  1. Nouvelle NC. Tapez le MSN de l’avion, choisissez le Produit, et cliquez sur l’étape où le défaut a été vu (Détection : Poste, Test, Contrôle Final, Réception, Client, Autre). Puis Continuer.
  2. Contexte de découverte (optionnel) : cliquez sur un début de phrase, comme Lors du contrôle final, et complétez-le si besoin. Un second clic le retire.
  3. Ajouter un défaut, pour chaque défaut, en trois étapes :
    • Nature : tapez un mot ou un code dans la recherche (contact, obturateur, T04… ; les accents ne comptent pas), ou cliquez sur une famille. Les familles de l’inspection (Q01 à Q16) et celles du test (T01 à T08) forment deux groupes ; celles du test viennent en premier quand la détection est Test.
    • Objet : cliquez sur l’élément concerné. Chacun montre son sous-code et sa sévérité habituelle ; CDVE possible signale une variante commandes de vol.
    • Détails : la Localisation (FIN / zone), choisie parmi les FIN proposés pour ce code ou tapée dans la case en dessous ; une Précision et un Complément libre si utile (tous deux optionnels) ; la Quantité ; la Sévérité, donnée par le code, que vous pouvez changer. Pour un circuit de commandes de vol, l’interrupteur CDVE passe le code à sa variante CDVE et la sévérité à majeure. Ligne générée montre la ligne telle qu’elle sera écrite. Puis Enregistrer le défaut.
  4. Action demandée (optionnel) : cliquez sur une phrase, comme Merci de remettre en conformité, et ajoutez vos mots.
  5. Vérifier et soumettre : l’écran Vérification montre le tableau des défauts et, à droite, le texte exactement tel qu’il sera envoyé. Retour aux défauts permet de corriger.
  6. Soumettre la NC. La page affiche NC prête à enregistrer : la NC est prête, pas encore enregistrée.
  7. Vérifiez la NC dans le formulaire d’enregistrement, puis appuyez sur Submit : la NC est enregistrée. Nouvelle NC commence la suivante.

Dans la liste des défauts, Dupliquer le dernier commence un nouveau défaut à partir du dernier, avec le même code et le même FIN : pratique pour une série du même défaut. Chaque défaut se modifie ou se supprime avec ses deux boutons ; les lignes sont renumérotées. Modifier, en haut, change le MSN, le produit ou la détection.

Le texte qu’il écrit

### DEFAUTS v1 | PRODUIT: CA Superior | DETECTION: CONTRÔLE FINAL

Lors du contrôle final

DEF 1 - Q01-001 : 100VG301 — Contact — broche 12
DEF 2 - Q03-006 - QTE 3 : 3CBB — Collier

Merci de remettre en conformité

### TOTAL: 4

La première ligne donne le format, le produit et l’étape où le défaut a été vu. Puis vient une ligne par défaut : son numéro, son code officiel, sa quantité quand il y en a plusieurs, le FIN, l’élément et vos mots. La dernière ligne donne la quantité totale : un contrôle qu’aucun défaut ne s’est perdu en route.

Le texte est fait pour SAP : collez-le tel quel dans la NC, sans toucher à ses lignes DEF. Le tableau de bord les lit une à une, même après les étoiles et les espaces ajoutés par SAP.

Les contrôles qu’il fait

  • Continuer reste grisé tant que le MSN, le produit et la détection ne sont pas remplis.
  • Aucun FIN n’est choisi pour vous : vous le choisissez ou le tapez.
  • Un défaut ne peut pas être enregistré avec une quantité qui n’est pas un nombre entier d’au moins 1, ni avec Autre comme localisation sans rien taper : un message rouge dit quoi corriger.
  • Vérifier et soumettre reste grisé tant que la NC n’a aucun défaut.
  • Si l’envoi échoue, la page le dit et la NC n’est pas perdue : copiez le texte avec Copier, ou réessayez.

Les produits proposés

MIP A350, MIP 400M, 740VU, PTVU, 300VU, OHP, E Rudder, MFRL, MDCD, et les produits REC CA, CA Superior et Element OTP. Pour un autre produit, choisissez Autre et tapez-le sous la liste.

Quand quelque chose n’est pas dans la liste

  • Un produit ou une détection : choisissez Autre et tapez-le.
  • Un FIN : tapez-le dans la case sous la liste, ou choisissez Autre et tapez-le. Une zone convient quand il n’y a pas de FIN.
  • Un code : la liste est la fiche de codes officielle de l’usine. Essayez un autre mot, ou le code lui-même, ou ouvrez les familles une à une. Si aucun code ne convient vraiment, n’en prenez pas un qui s’en approche seulement : le code décide de la cause sur le tableau de bord (ci-dessous). Signalez au responsable du tableau de bord le défaut qui n’avait pas de code, pour que la liste soit vérifiée face à la fiche de codes officielle.

Pourquoi le code décide de la cause sur le tableau de bord

Sur le tableau de bord, chaque défaut est classé dans une cause, à l’intérieur d’une catégorie. Pour une NC écrite avec cet outil, le code officiel de chaque défaut décide de sa cause, devant tout classement automatique. Sans code, la cause est déduite des mots du texte, ce qui peut être moins précis. Le tableau de bord range donc chacun de vos défauts directement dans la cause de son code, dans chaque graphique, dans la cloche et dans les actions MFT. Choisissez le code avec soin : c’est la cause qui sera comptée.
