À quoi sert l’onglet

L’onglet Retours clients montre les NC émises hors de FTO2, par les lignes d’assemblage ou les clients, dont FTO2 est responsable. Ce sont des défauts qui sont sortis de l’usine : ils pèsent donc plus que leur nombre ne le laisse penser. L’onglet les compte en défauts. Les chiffres clés donnent le nombre de retours, la part d’éléments endommagés, la part de dommages physiques, et leur coût.

Bon à savoir

  • Le filtre Usine FTO2 uniquement n’a pas d’effet ici : cet onglet ne montre que des NC émises hors de FTO2.
  • Le coût d’un retour est estimé avec le même modèle que les autres NC ; les factures réelles ne sont pas disponibles.
