À quoi sert l’onglet

L’onglet Définitions est le dictionnaire du tableau de bord. Chaque graphique qui montre une catégorie ou une cause utilise les mots définis ici. C’est là qu’on tranche la question « que couvre exactement cette cause ? », avec des chiffres et des exemples réels.

Le contenu

Comment un défaut reçoit sa cause

Ce qu’on voitLa chaîne du code officiel jusqu’au Pareto : 123 sous-codes officiels → 42 sous-catégories → 25 causes → 9 catégories.
Comment le lireChaque sous-catégorie donne une seule cause, chaque cause appartient à une seule catégorie. Un code officiel écrit dans la NC décide ; sinon, c’est le texte de la NC qui décide, et un défaut décrit avec sa cause et sa conséquence est classé sur la cause.
