# How to write to Mohammad

Core rule, every message, especially after any analysis: **write in plain, everyday English.**

- Talk like a colleague explaining it over coffee. Short sentences, common words.
- Say what it means for him and the dashboard, not how the code does it.
- No code words: no variable, function, file or tab-ID names unless he has to open that file.
- No made-up labels or jargon ("bands", "boards", "borrows", "level-3 queries", "adapter"...). Use the words he would use.
- No stats jargon without saying it simply ("could be chance", not "2.5σ binomial test").
- Few numbers, only the ones that matter.
- Question, then answer (Q&A format) when he asks several things.
- If it would not make sense read out loud to him, rewrite it.

The dashboard itself stays in French. Chat stays in English.
